# BCA303P – Lab Sheet 3: Flutter User Input and Basic Interaction

This repository contains 25 standalone Flutter/Dart examples corresponding to the 25 programs listed in `BCA303P-AS03.pdf`.

## Contents
Each `Program_XX` folder contains:
- `main.dart` — complete standalone Flutter example
- `README.md` — short run instructions

## Run any program
1. Install Flutter and confirm setup with `flutter doctor`.
2. Create a project: `flutter create my_app`
3. Copy the desired `Program_XX/main.dart` to `my_app/lib/main.dart`, replacing the existing file.
4. Run `cd my_app` then `flutter run`.

These are educational UI examples. Login and registration screens do not connect to a server or authenticate users. The student-result example assumes each subject is out of 100 and uses 33 marks as the pass threshold; change the threshold if your institution specifies another rule.
